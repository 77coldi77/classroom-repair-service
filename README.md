# Сервис подачи и отслеживания заявок на ремонт оборудования в учебных аудиториях

## 1. Описание проекта

Проект представляет собой веб-сервис, предназначенный для подачи, обработки и отслеживания заявок на ремонт оборудования в учебных аудиториях образовательного учреждения.

Система позволяет преподавателям и сотрудникам сообщать о неисправностях оборудования, а техническим специалистам — получать заявки, изменять их статус и контролировать выполнение ремонтных работ.

## 2. Основные возможности

- Регистрация и авторизация пользователей.
- Создание заявок на ремонт оборудования.
- Указание номера учебной аудитории и типа неисправности.
- Просмотр списка отправленных заявок.
- Отслеживание статуса выполнения заявки.
- Назначение ответственных технических специалистов.
- Изменение статусов заявок.
- Просмотр истории выполненных ремонтов.
- Формирование отчетов по заявкам.

## 3. Используемые технологии

- Frontend: React, JavaScript, CSS.
- Backend: Node.js, Express.js.
- База данных: PostgreSQL.
- Система контроля версий: Git.
- Платформа хранения проекта: GitHub.

## 4. Роли пользователей

- Преподаватель — создание заявок и отслеживание их выполнения.
- Технический специалист — обработка заявок и выполнение ремонта.
- Администратор — управление пользователями и контроль работы системы.

## 5. Структура проекта

- frontend/ — клиентская часть приложения.
- backend/ — серверная часть приложения.
- docs/ — документация проекта.
- README.md — описание проекта.
- .gitignore — исключаемые файлы.

## 6. Запуск проекта

Инструкция по установке зависимостей и запуску приложения будет добавлена после реализации программных модулей.

## 7. Цель проекта

Создание удобного инструмента для автоматизации процесса подачи и обработки заявок на ремонт оборудования в учебных аудиториях, сокращения времени реагирования на неисправности и повышения эффективности технического обслуживания.
